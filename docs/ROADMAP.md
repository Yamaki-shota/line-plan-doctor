# ロードマップ

## 目標

LINE Plan Doctor は、LINE/Lステップ案件の「公開直前に気づく抜け」を、資料作成の段階で見つける道具にします。

## 直近

- チェックルールを20個まで増やす
- 実案件から汎用化したサンプルを追加する
- JSON出力をGitHub Actionsで扱いやすくする
- 複数ファイル診断の表示を見やすくする
- READMEに非エンジニア向けの使い方を足す

## 次

- Obsidian Vault内の案件フォルダをまとめて診断
- チェック結果から修正用チェックリストを生成
- Codexに渡すレビュー指示を生成
- `--strict` モードを追加

## やらないこと

- 案件資料を勝手に外部送信する
- LINE公式やLステップの本番環境を直接操作する
- 個別案件の実IDや本番文面をサンプルに入れる
- 依存ライブラリを増やしてセットアップを重くする
